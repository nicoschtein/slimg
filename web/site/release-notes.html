Release notes

What's new in Slimg, newest version first.

Slimg 1.1.1

November 11, 2026

  • Photos stay the right way up. Some camera and phone photos record their rotation only in the EXIF data that Slimg removes, so they could come out rotated or mirrored. Slimg now keeps that one setting and removes the rest.
  • Adobe RGB photos stay marked. Photos from cameras set to Adobe RGB that carry no color profile keep the marker that says so, so photo software that reads it still shows the right colors. It's still removed when you choose to strip color data.
  • Careful with damaged EXIF data. When a photo's EXIF data is damaged or laid out in an unusual way, Slimg leaves it as it is instead of guessing.

Slimg 1.1.0

October 26, 2026

  • iPhone photos. Slimg now works with HEIC and HEIF photos. It removes location, camera and other descriptive data without re-encoding the picture, and keeps the orientation and color profile.
  • Seven more ways to save space. New settings for deep PNG compression, Zopfli, exact PNG color storage, PNG chunk and profile optimization, JPEG Huffman coding, progressive JPEG and GIF recompression. All are off until you turn them on, never change a pixel, and keep a result only when it's smaller.
  • Nothing else to install. The extra compression libraries are built into the app and the command-line tool.
  • Checked before release. Every build now runs the full test suite before it's packaged.

Slimg 1.0.0

June 15, 2026

  • First release. Slimg makes JPEG, PNG and GIF files smaller without changing a single pixel, and never makes a file larger.
  • JPEG. Removes camera, XMP, Photoshop and IPTC data and comments. The picture data is copied byte for byte, and the color profile stays.
  • PNG. Removes text, timestamp and EXIF chunks, and recompresses the image data with the same pixels.
  • GIF. Removes comments and extra application data. Frames, timing and looping stay as they were.
  • The app. Drag in files or whole folders, see the savings on each file, and open a report of everything that was removed. Originals are kept as name.bak.ext.
  • The command-line tool. slimg with --dry-run, --backup, --report, --keep-metadata, --strip-color and --no-recompress.
