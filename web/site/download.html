Get Slimg for Mac.

Version 1.1.0. Free. macOS 13 or later, on Apple silicon and Intel.

The app

Download Slimg.dmg SHA-256 checksum

  1. Open the download

    Double-click Slimg.dmg in your Downloads folder.

  2. Drag Slimg to Applications

    Drop the Slimg icon on the Applications folder in the window that opens.

  3. Open it the first time

    In Applications, Control-click Slimg, choose Open, then Open again. You only do this once.

Slimg isn't notarized by Apple yet, so macOS asks before it opens the first time. Opening it with Control-click tells your Mac you trust it.

The command-line tool

Download slimg-cli-macos.tar.gz SHA-256 checksum

Unpack it and move slimg onto your path:

tar -xzf slimg-cli-macos.tar.gz
sudo mv slimg /usr/local/bin/
slimg --help

If macOS stops the tool from running, clear the download flag once:

xattr -d com.apple.quarantine /usr/local/bin/slimg

Every option is on the support page.

Build it yourself

Slimg is open source under the MIT License. With Xcode 15 or later, clone the source code and run ./Scripts/build-app.sh.
