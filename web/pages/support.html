Getting started

  1. Install Slimg

    Get Slimg.dmg from the download page and drag Slimg to Applications.

  2. Drop your images

    Drag photos, screenshots or whole folders onto the Slimg window, or click Add Images. Slimg starts right away.

  3. Check the savings

    Each row shows how much smaller the file got. Click the report button on a row to see what came out.

  4. Keep or clear the originals

    With Keep originals on, the old file stays next to the new one as name.bak.jpg. Delete those once you're happy.

Want more savings? Open Slimg > Settings and turn on the methods under Additional lossless optimization. They take longer and never change a pixel.

The command line

slimg works on the files you name and changes them in place. Add --backup to keep the originals.

slimg --backup --report photo.jpg
slimg --dry-run *.png
Options
--dry-runShow the savings without writing any file.
--backup, --copyKeep each original as name.bak.ext.
--report, -vList what was removed from each file.
--keep-metadataLeave camera, XMP and IPTC data and comments in.
--strip-colorAlso remove color profiles. Colors can look different afterward. HEIC profiles always stay.
--no-recompressSkip the standard PNG recompression.
--deep-pngTry more PNG filters and compression strategies.
--zopfli-pngSearch hardest for the smallest PNG. Much slower.
--reduce-pngStore PNG colors in fewer bits when every value stays exact.
--optimize-pngMerge PNG image chunks and recompress kept color profiles.
--optimize-jpegPack the existing JPEG data with better Huffman tables.
--progressive-jpegTry progressive JPEG, kept only when smaller.
--recompress-gifRepack GIF frames with the animation unchanged.

slimg doesn't open folders by itself. To work through one, let your shell list the files, for example slimg **/*.png in zsh.

Troubleshooting

macOS says Slimg can't be opened.

Slimg isn't notarized by Apple yet. Click Done, then open System Settings > Privacy & Security, scroll down to Security and click Open Anyway next to the note about Slimg. Enter your password and click Open Anyway again. You only need to do this once.

A file says "Already optimal".

Slimg couldn't make it any smaller without changing a pixel, so it left the file as it was. Turning on more methods in Settings sometimes finds a little more.

A file says "Unsupported format".

Slimg works with JPEG, PNG, GIF, HEIC and HEIF. HEIF files that use a codec other than HEVC, such as AVIF, aren't supported yet.

A file didn't get any smaller.

Some files carry no extra data to remove. Images exported for the web are often stripped already.

Colors look different after Slimg.

Check that Strip color profiles is off in Settings, or that you didn't pass --strip-color. Slimg keeps color profiles unless you ask it to remove them.

I see a lot of .bak files.

Those are your originals, kept because Keep originals is on. Delete them when you no longer need them, or turn the switch off to change files in place.

The slimg command isn't found.

Check that slimg is in a folder on your path, such as /usr/local/bin. Running which slimg shows where your shell finds it.

Questions

Does Slimg change how my images look?

No. Open the new file and every pixel has the same value as before. Slimg removes data you can't see and stores the same pixels in less space.

Can a file come out bigger?

No. If Slimg can't make a file smaller, the file stays exactly as it was.

Does Slimg upload my images?

No. Everything happens on your Mac, and Slimg works with Wi-Fi off.

What does Slimg remove?

Camera details and location (EXIF), Adobe XMP and IPTC data, comments and timestamps. It keeps the color profile and everything needed to decode the picture.

How is this different from TinyPNG?

TinyPNG and similar tools change pixels to get smaller files, and many upload your images to do it. Slimg never changes a pixel and never uploads. Its savings are smaller, and the picture is exactly the one you started with.

Can I run Slimg on the same folder again?

Yes. Files that are already slim are left alone, and nothing gets worse with each run.

Does it work with photos from my iPhone?

Yes. Slimg removes location and camera data from HEIC photos without re-encoding the picture. The orientation and color profile stay.

System requirements

macOS 13 Ventura or later, on a Mac with Apple silicon or an Intel processor.
