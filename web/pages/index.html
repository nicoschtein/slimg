Also in Slimg.

  • Never largerIf a file can't get smaller, Slimg leaves it as it was.
  • Originals keptThe original stays next to the new file as name.bak.jpg.
  • True colorsColor profiles stay in unless you choose to remove them.
  • iPhone photosHEIC photos lose their location and camera data, never their picture.
  • Deep PNG compressionTries more ways to pack the same PNG pixels.
  • ZopfliA slow, thorough search for the smallest PNG.
  • Exact PNG colorsStores colors in fewer bits only when every value stays exact.
  • JPEG codingPacks the same JPEG data tighter, with optional progressive loading.
  • GIF recompressionRepacks every frame and keeps the animation timing as it was.
  • Preview firstslimg --dry-run shows the savings without touching a file.
